This a repo that summerizes my attempts to approaching multi-vehcle coordination with joint optimization. Please see the video below. I use speed sampling to select the best modality among vehicles and use joint opt to optimize the corresponding sva. This method can also be applied to decentralized systems (e.g. robotaxis) but may need to switch joint opt objective from a common goal to a nash equilibrium.
